02 / MODELOS DE SERVIÇO

IaaS, PaaS e SaaS

Os modelos definem quanto da infraestrutura fica sob responsabilidade do provedor e quanto fica sob responsabilidade do cliente.

01

IaaS

Infrastructure as a Service.

Mais controle sobre sistema operacional, rede e infraestrutura virtual.

Ex.: EC2, Azure VM, Compute Engine
02

PaaS

Platform as a Service.

O provedor gerencia a infraestrutura e o desenvolvedor foca no código e nos dados.

Ex.: Elastic Beanstalk, App Service, App Engine
03

SaaS

Software as a Service.

Aplicação pronta para uso, acessada pelo usuário sem gerenciar servidores.

Ex.: Google Workspace, Microsoft 365

03 / INFRAESTRUTURA GLOBAL

Regiões e zonas de disponibilidade

A distribuição global ajuda a reduzir latência, aumentar disponibilidade e melhorar a resiliência das aplicações.

Região

Área geográfica onde um provedor mantém um conjunto de data centers interconectados.

Zona de disponibilidade

Infraestrutura isolada dentro de uma região para ajudar na tolerância a falhas.

Latência

Quanto menor a distância entre o usuário e a infraestrutura, menor tende a ser o tempo de resposta.

AWS 39 regiões / 124 AZs
Azure 70+ regiões / 400+ data centers
GCP 38 regiões / 115 AZs
